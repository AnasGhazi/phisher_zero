# Assets Folder

This folder should contain the extension icons:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

You can create icons using:
1. Any image editor (Photoshop, GIMP, Figma, etc.)
2. Online icon generators
3. SVG to PNG converters

The icon should represent a shield or security symbol to match the Phisher Zero branding.

## Quick Icon Generation

You can use online tools like:
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/
- Or create a simple shield icon in your preferred design tool

For now, you can use any placeholder images to test the extension. The extension will work without icons, but Chrome may show warnings.
